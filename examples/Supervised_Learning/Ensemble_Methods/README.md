# Ensemble methods examples

Random forest notebooks that build on **`rice_ml.Supervised_Learning.ensemble_methods`**.

## Notebooks

| Notebook | Notes |
|----------|--------|
| **`Random_Forest.ipynb`** | Random forest walkthrough (one variant). |
| **`Random_Forests.ipynb`** | Extended or alternate random forest example; may share datasets with other supervised notebooks (e.g. spam CSV under `examples/datasets/`). |

## Prerequisites & run

Same as [Supervised learning examples](../README.md):

```bash
# from repo root
pip install -e .
jupyter notebook examples/Supervised_Learning/Ensemble_Methods/
```

## Data

Spam and other CSVs: **`examples/datasets/`**. Use **`examples/load_dataset.py`** for paths that work on any clone.
