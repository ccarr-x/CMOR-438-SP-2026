# Neural Networks Examples

Example notebooks for `rice_ml.Neural_Networks`.

## Notebooks

- `Neural_Network.ipynb` - demonstrates:
  - binary classification with `SigmoidNeuralNetwork`
  - regression with `DenseNetwork`
  - simple training-loss and prediction plots

## Quick Start

From project root:

```bash
pip install -e .
jupyter notebook examples/Neural_Networks/
```
